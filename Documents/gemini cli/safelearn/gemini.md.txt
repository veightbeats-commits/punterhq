# QCTO Learner Protection Platform - Master Development Prompt

## Project Overview
Build a comprehensive web application that protects South African learners from unaccredited "fly-by-night" schools by providing easy access to verified QCTO qualifications, skills programmes, and accredited training providers.

## Mission Statement
Help learners verify legitimate qualifications and accredited institutions before enrolling, preventing fraud and ensuring their education investment is recognized by employers and government.

---

## Database Structure

### You have 3 CSV databases:

#### 1. **accredited-schools.csv**
Contains QCTO-accredited Skills Development Providers (SDPs)
- Fields likely include: Provider Name, Accreditation Number, Contact Info, Status, Qualifications Accredited For, Expiry Date, Physical Address

#### 2. **skill-programmes.csv**  
Contains QCTO Skills Programmes
- Fields likely include: Programme ID, Title, NQF Level, Credits, Duration, Category, Status, Entry Requirements, Description

#### 3. **Registered-Quals-Part-Reg-Quals.csv**
Contains Full Occupational Qualifications and Part Qualifications with SAQA links
- Fields likely include: Qualification ID (SAQA ID), Title, Type (Full/Part), NQF Level, Credits, Duration, Category, Registration Date, End Date, Status, SAQA Link, Description, Components, Entry Requirements

## Database Schema Design

### Table: qualifications
```sql
CREATE TABLE qualifications (
    id SERIAL PRIMARY KEY,
    saqa_id VARCHAR(20) UNIQUE NOT NULL,
    title VARCHAR(500) NOT NULL,
    type VARCHAR(50), -- 'Full Qualification' or 'Part Qualification'
    nqf_level INTEGER,
    credits INTEGER,
    duration VARCHAR(100),
    category VARCHAR(200),
    status VARCHAR(100),
    registration_date DATE,
    end_date DATE,
    saqa_link TEXT,
    description TEXT,
    entry_requirements TEXT,
    components TEXT[], -- Array of qualification components
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_qualifications_saqa_id ON qualifications(saqa_id);
CREATE INDEX idx_qualifications_title ON qualifications(title);
CREATE INDEX idx_qualifications_nqf_level ON qualifications(nqf_level);
CREATE INDEX idx_qualifications_category ON qualifications(category);
```

### Table: skills_programmes
```sql
CREATE TABLE skills_programmes (
    id SERIAL PRIMARY KEY,
    programme_id VARCHAR(20) UNIQUE,
    title VARCHAR(500) NOT NULL,
    nqf_level INTEGER,
    credits INTEGER,
    duration VARCHAR(100),
    category VARCHAR(200),
    status VARCHAR(100),
    description TEXT,
    entry_requirements TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_skills_title ON skills_programmes(title);
CREATE INDEX idx_skills_nqf_level ON skills_programmes(nqf_level);
```

### Table: accredited_schools
```sql
CREATE TABLE accredited_schools (
    id SERIAL PRIMARY KEY,
    school_name VARCHAR(500) NOT NULL,
    accreditation_number VARCHAR(100) UNIQUE,
    status VARCHAR(50), -- 'Active', 'Expired', 'Suspended'
    physical_address TEXT,
    postal_address TEXT,
    province VARCHAR(100),
    city VARCHAR(100),
    contact_number VARCHAR(50),
    email VARCHAR(255),
    website VARCHAR(255),
    accreditation_date DATE,
    expiry_date DATE,
    qualifications_accredited_for TEXT[], -- Array of qualification IDs
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_schools_name ON accredited_schools(school_name);
CREATE INDEX idx_schools_accreditation_number ON accredited_schools(accreditation_number);
CREATE INDEX idx_schools_province ON accredited_schools(province);
```

### Table: school_qualifications (Junction table)
```sql
CREATE TABLE school_qualifications (
    id SERIAL PRIMARY KEY,
    school_id INTEGER REFERENCES accredited_schools(id),
    qualification_id INTEGER REFERENCES qualifications(id),
    programme_id INTEGER REFERENCES skills_programmes(id),
    accreditation_scope TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);
```
